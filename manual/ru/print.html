Справочник kadr

kadr

Скриншоты и запись экрана: снять область, окно или весь экран, разметить, записать видео с камерой и кликами и превратить запись в аккуратный ролик. Написан на Rust и GPUI CE. Сначала для Linux под Omarchy (Arch, Hyprland, Wayland), дальше macOS и Windows. Интерфейс на английском и русском, тёмная и светлая темы следуют системе.

Этот справочник описывает, что kadr умеет сейчас, экран за экраном. У каждой страницы одно устройство: зачем экран, как открыть, что на нём, клавиши, какие настройки на него влияют и какие команды его запускают. Что менялось от версии к версии, в списке изменений; куда идёт проект, в роадмапе.

Страницы

  • Установка: сборки, что нужно kadr на каждой системе, хук для Hyprland.
  • Съёмка: панель съёмки, выбор области, снимки окна и экрана, снимок с прокруткой, таймер, карточка после снимка, закрепление, распознавание текста.
  • Редактор: разметка скриншота: инструменты, стили текста, скрытие, обрезка, фон, пресеты, сохранение.
  • Запись: панель записи, микрофон и звук системы, пузырь камеры, режим студии, обрезка и GIF.
  • Студия: из записи в ролик: зумы, вырезки, курсор, камера, экспорт.
  • История: все снимки и записи, с поиском и фильтрами.
  • Настройки: окно настроек, горячие клавиши и файл settings.toml.
  • Файлы проектов: файлы .kadr, которые хранят правку.
  • Командная строка: все команды kadr.
  • Словарь: слова, которыми пользуются справочник и kadr.

Платформы

  • Linux (Wayland, Hyprland): работает всё, здесь kadr используется каждый день.
  • macOS и Windows: редактор, студия, скриншоты (в том числе окна и снимки с прокруткой), запись через системный захват, буфер обмена, уведомления, трей, глобальные хоткеи и оверлей выбора области написаны и проходят сквозной тест на раннерах CI. Камера, выбор микрофона и лог кликов и клавиш для студии пока не перенесены, и живьём там kadr никто не запускал: тестеры очень нужны.

Помощь

Ошибки и вопросы в GitHub issues. После падения в папке кэша kadr остаётся crash.log, приложите его. Разработчикам: CONTRIBUTING.md.

Установка

Скачайте готовую сборку или соберите kadr из исходников с Rust 1.95 или новее. Основная платформа — Linux на Wayland с Hyprland.

Скачать

В Releases есть .tar.xz для Linux с INSTALL.md внутри, .dmg с Kadr.app для macOS на Apple silicon или Intel, а также установщик и портативный .exe для Windows.

Сборки пока не подписаны. После копирования приложения macOS в Applications выполните:

xattr -dr com.apple.quarantine /Applications/Kadr.app

Linux (Hyprland)

Установите gpu-screen-recorder, ffmpeg, tesseract с английскими языковыми данными, grim и wl-clipboard. В Omarchy они могут уже стоять; если нет, установите через pacman. mpv не обязателен: через него играют «Проиграть» в окне обрезки и «Предпросмотр» в студии.

Чтобы собрать из исходников и установить обе программы:

cargo build --profile dist -p kadr -p kadr-tray
install -m755 target/dist/kadr target/dist/kadr-tray ~/.local/bin/

Скопируйте хук Hyprland из исходников:

cp data/hypr/kadr.lua ~/.config/hypr/kadr.lua

Добавьте require("hypr.kadr") в ~/.config/hypr/hyprland.lua. Хук делает окна kadr плавающими, загружает сочетания, сохранённые в настройках, и пишет клики и сочетания клавиш во время записи для студии. На Linux kadr начинает с ваших привязок Hyprland, а не с глобальных сочетаний по умолчанию для других систем.

Запускайте kadr-tray при входе. В Omarchy добавьте в autostart.lua:

o.launch_on_start("kadr-tray")

При первом запуске на Linux kadr регистрирует тип файлов проектов .kadr, иконку и пункт меню. Вручную это делает kadr install-desktop.

macOS и Windows

При сборке из исходников соберите все три программы и держите kadr, kadr-tray и kadr-overlay рядом:

cargo build --profile dist -p kadr -p kadr-tray -p kadr-overlay

Глобальные сочетания держит трей, поэтому запускайте kadr-tray при входе. Сочетания по умолчанию и их настройка описаны в настройках. Установщик Windows настраивает трей при входе и открытие файлов .kadr; портативная сборка — один kadr.exe.

Неподписанные сборки также прикладываются к запущенным вручную прогонам в Actions. Для таких отдельных программ macOS перед запуском снимите карантин:

xattr -d com.apple.quarantine kadr kadr-tray kadr-overlay

На macOS и Windows реализованы скриншоты, снимки окон, редактор, студия и запись системными средствами захвата. Снимки с прокруткой там тоже доступны. Есть тесты на CI, но на живых машинах эти системы ещё не проверяли. Лог кликов и клавиш через Hyprland работает только на Linux.

Обновление

Если в настройках включено «Основные → Проверять обновления», трей проверяет новые версии раз в день. Новый релиз появляется на карточке обновления. «Страница релиза» открывает описание и загрузки; «Обновить» скачивает релиз, проверяет его подпись и заменяет установленные файлы. Трей перезапускается на новой версии. Если версия трижды подряд не запускается, возвращается предыдущая. Установки через пакетный менеджер обновляются через него.

В разделе «Основные» выберите «Канал обновлений»: «Стабильный» получает только готовые версии, «Бета» — ещё и альфы, беты и кандидаты в релиз. Предварительная сборка использует бету, пока вы не смените канал.

Чтобы проверить сразу, откройте «Настройки → О kadr → Проверить сейчас». Эта же строка показывает результат и предлагает обновление. kadr update показывает результат на карточке.

Команды

  kadr settings                                  settings
  kadr update                                    look for a newer release now
  kadr tray                                      tray icon (for autostart)
  kadr install-desktop                           let .kadr project files open in kadr (file type, icon, menu entry)

kadr install-desktop работает только на Linux. Все команды — на странице командной строки.

Съёмка

Всё, что снимает экран: область, окно, весь экран или все экраны сразу, длинный снимок с прокруткой, снимок по таймеру. После снимка в углу экрана появляется карточка: с неё картинку можно скопировать, открыть в редакторе, закрепить поверх окон или распознать на ней текст. Здесь же распознавание текста и закрепление.

Как открыть

  • Панель съёмки (kadr capture) собирает все режимы на одной панели, так что хватает одной горячей клавиши. По умолчанию клавиши у неё нет: назначьте её в «Настройки» → «Клавиши» → «Все режимы на одной панели».
  • Горячие клавиши. На macOS и Windows по умолчанию Ctrl+Shift+1 снимает область, Ctrl+Shift+3 распознаёт текст, Ctrl+Shift+6 делает скриншот с прокруткой. На Linux kadr берёт ваши привязки из Hyprland. Другим действиям (прошлая область, окно или область, весь экран) клавишу можно назначить в «Настройки» → «Клавиши».
  • Меню трея: «Скриншот», «Распознать текст», «Скриншот с прокруткой».
  • Команды: kadr shot, kadr shot scroll, kadr text, kadr pin; см. Команды.

Панель съёмки

Панель появляется внизу экрана, на ней восемь режимов в трёх группах:

Кликните по режиму, нажмите его цифру или переберите стрелками влево и вправо и нажмите Enter. Esc, клик мимо панели или та же горячая клавиша ещё раз её закрывают.

Выбор области

Экран замирает, и вы тянете по нему рамку. Строка подсказок показывает, что сейчас делают клавиши.

  • Потяните, чтобы нарисовать область; она снимается, как только отпустите кнопку мыши. С Shift получается квадрат. Если во время рисования держать Пробел, рамка не растёт, а двигается целиком.
  • Клик без протягивания: над окном снимает это окно, над пустым местом копирует цвет под курсором в виде кода (#RRGGBB), и kadr пишет «Цвет скопирован».
  • Пробел переключает на выбор окон: клик снимает окно под курсором, рамка не рисуется. Ещё раз Пробел — снова рисование области.
  • Оставить область, чтобы поправить. Нажмите стрелку, A, P или цифру, пока рамка на экране, и она останется после того, как отпустите мышь. Дальше её можно тянуть за ручки, двигать, взявшись изнутри, или снять двойным кликом внутри.
  • Стрелки двигают область на пиксель, Shift+стрелки — на десять. Alt+стрелки растягивают или сжимают её за правый и нижний края.
  • A перебирает пропорции: «Свободно», 1:1, 4:3, 16:9, 9:16.
  • Цифры задают точный размер в пикселях экрана: ширина, потом X (или Tab, или Пробел) и высота, потом Enter. Если высоту не ввести, она берётся по пропорциям.
  • P возвращает последнюю область, выбранную на этом экране, чтобы её поправить. Enter, пока ничего не нарисовано, сразу снимает эту область.
  • Enter снимает область, Esc отменяет.

Режим «Область» и kadr shot region не прилипают к окнам: клик там только копирует цвет.

Окна, экраны и прокрутка

  • Окно снимается само по себе, что бы его ни закрывало, со скруглёнными углами и мягкой тенью на прозрачном фоне. Тень выключается настройкой «Тень окна». «Фон снимка окна» сразу кладёт окно на фон, сохранённый в редакторе; редактор открывает такой снимок с этим фоном, и его ещё можно поменять. Снимки окон работают на Linux, macOS и Windows.
  • Весь экран снимает экран, на котором фокус.
  • Все экраны сразу (kadr shot all): все мониторы на одной картинке, расставленные так же, как на вашем рабочем столе.
  • Таймер отсчитывает поверх экрана 3, 5 или 10 секунд (настройка «Таймер») и снимает его. Esc отменяет отсчёт.
  • Курсор может попадать в снимок: включите «Курсор в скриншотах».

Снимок с прокруткой: выберите область и прокручивайте её сами. kadr всё время снимает область и склеивает то, что появляется, в одну длинную картинку. Прокручивать можно вниз по странице и вбок, вправо (таймлайн, широкая таблица) — тогда получится одна широкая картинка.

Вокруг области появляется рамка, а рядом панель «Прокручивай — kadr склеит» с текущей длиной в пикселях. «Готово» или та же горячая клавиша ещё раз сохраняют снимок, «Отмена» его выбрасывает. Снимки с прокруткой работают на Linux, macOS и Windows.

Карточка после снимка

В углу экрана выезжает карточка с картинкой. По умолчанию снимок ещё и сразу копируется в буфер обмена. Наведите на карточку, чтобы появились кнопки:

  • «Копировать» кладёт картинку в буфер обмена и закрывает карточку.
  • «Редактировать» открывает снимок в редакторе. Двойной клик по карточке делает то же.
  • «Закрепить поверх окон» (справа вверху): снимок висит над всеми окнами, см. ниже.
  • «Распознать текст» (справа внизу) читает текст на картинке.
  • «Показать в папке» (справа внизу).
  • «Удалить файл» (слева внизу) отправляет файл в корзину.
  • «Закрыть» (слева вверху).

Перетащите карточку в чат, браузер или файловый менеджер, чтобы бросить туда файл. Смахните её к краю экрана, чтобы убрать.

Карточка исчезает через 10 секунд (по умолчанию), а пока на ней курсор, остаётся. Сколько она висит, в каком углу и сколько карточек сразу, задаётся в «Настройки» → «Основные».

Закрепление

Закреплённая картинка висит поверх всех окон в своём настоящем размере: удобно держать образец перед глазами, пока работаете. Закрепить снимок можно с его карточки, с нижней панели редактора, из истории (P), командой kadr pin или сразу каждый снимок («Закрепить поверх окон» в разделе «После снимка»).

  • Тащите, чтобы передвинуть; стрелки сдвигают на пиксель, Shift+стрелки — на десять.
  • Колесо мыши меняет масштаб, Alt+колесо или Ctrl+колесо — прозрачность.
  • L пропускает клики к окнам под картинкой. Клики ловит только замок в её углу: нажмите его или L, чтобы снова ловить клики.
  • Esc, двойной клик или правый клик закрывают картинку.

Распознавание текста

kadr text замораживает экран: выберите область, и её текст окажется в буфере обмена. Карточка показывает, что найдено, с кнопкой «Скопировать ещё раз», а если в тексте есть ссылка, то и «Открыть ссылку». QR-коды тоже читаются, если установлен zbar. С картинкой (kadr text <image> или «Распознать текст» на карточке) kadr читает её целиком.

kadr читает английский и русский, а ещё украинский, немецкий, французский и испанский, если они есть у Tesseract. Для русского нужны русские данные Tesseract: в Arch это пакет tesseract-data-rus, или «Настройки» → «Текст» → «Русский язык» скачивает их (15 МБ) в папку kadr, без sudo.

Редактор

В редакторе на скриншот ставят стрелки, рамки, текст и номера шагов, прячут личное, обрезают картинку и кладут её на фон. Нарисованное остаётся редактируемым: откройте сохранённый файл в редакторе снова, и все фигуры вернутся.

Редактор открывает картинки PNG, JPEG и WebP и файлы проектов .kadr.

Как открыть

  • Из карточки после снимка: Редактировать.
  • Сразу после каждого снимка: включите Настройки → Скриншоты → Открывать редактор.
  • Из истории: выберите скриншот и нажмите E или кнопку Редактировать.
  • Из командной строки: kadr edit <image|project.kadr>. kadr open с файлом .kadr тоже открывает его проект.
  • Из файлового менеджера: файлы .kadr открываются в kadr (см. Файлы проектов).

В Linux редактор по умолчанию открывается обычным окном, а может и закрывать весь экран (см. «Настройки» ниже). В macOS и Windows это всегда окно.

Инструменты

Картинку она читает через tesseract, его нужно установить.

Цвет, размер и настройки фигуры

  • Цвет и размер всегда в углу верхней панели. Они действуют на следующую фигуру и на выделенную.
  • В меню цвета восемь цветов kadr (клавиши 1–8), пипетка (I: щёлкните по картинке, чтобы взять с неё цвет), Последние цвета и Свои: + сохраняет туда текущий цвет, правый клик убирает.
  • Настройки самой фигуры появляются на панели под выделенной фигурой: вид стрелки, заливка рамки, стиль текста, способ скрытия, вид указателя. Стрелка, рамка, эллипс и скрытая область остаются выделенными после рисования, так что их панель сразу под рукой. Следующая фигура берёт то, что выбрано последним.
  • Отменить и повторить тоже в верхней панели.

Фон и пресеты

Кнопка фона в верхней панели открывает боковую панель:

  • Пресеты наверху: + сохраняет текущий вид пресетом, в выпадающем списке пресет выбирают, переименовывают или удаляют.
  • Нет, Градиенты (остальные по кнопке Ещё), Обои (фоны тем Omarchy, если они есть, и Своя картинка…), Размытый (сам снимок, размытый), Цвет (в том числе Прозрачный).
  • Ползунки Отступ, Углы и Тень.
  • Пропорции: Авто, 16:9, 4:3, 1:1 или 9:16. Под ними виден итоговый размер.
  • Положение: где картинка стоит на сетке 3×3. Не в центре она прижимается к этому краю или углу. Выровнять поля подрезает однотонные поля скриншота поровну, чтобы содержимое встало по центру.

К скриншоту можно добавить картинки:

  • если бросить картинку на скриншот, вставить через Ctrl+V или выбрать кнопкой Добавить картинку поверх, она ляжет сверху, как фигура;
  • если бросить её за краем скриншота, она пристроится к нему с этой стороны, той же высоты (или ширины). Пока вы тащите, редактор показывает, куда она встанет. На фоне пристроенные картинки становятся одной карточкой с общей тенью.

Обрезка

C (или кнопка обрезки в верхней панели) включает режим обрезки. Тяните края и углы рамки; пока включено Прилипать к краям, они прилипают к краям на картинке (Ctrl на время делает наоборот). Верхняя панель:

  • Пропорции: Свободно, Как у снимка, 1:1, 16:9, 9:16, 4:3, 3:2, 4:5, 21:9.
  • Ширина и высота в пикселях: щёлкните по полю и введите число; Tab переходит к другому.
  • Поменять ширину и высоту, Повернуть на 90° по часовой, Отразить по горизонтали.
  • Заливка за картинкой: рамка может выходить за картинку, и здесь выбирают, чем залить это место (прозрачным, белым, чёрным или цветом пера).
  • Размер: сохранить картинку поменьше: 100%, 75%, 50%, 33% или 25%.
  • Отмена и Обрезать.

Внизу масштаб, Прилипать к краям и Вернуть как было. После обрезки кнопка Без обрезки в нижней панели редактора возвращает картинку целиком.

Холст и нижняя панель

Холст масштабируется: Ctrl с колёсиком мыши приближает к указателю, колёсико без Ctrl или Space с перетаскиванием двигают картинку. В меню масштаба слева внизу есть По окну, 25%, 50%, 100% и 200%. Если файл открыт вместе с рисунком, там же появляется Начать заново: вернуть чистую картинку.

Нижняя панель слева направо:

  • Перетащи: перетащите готовую картинку в чат или папку.
  • Распознавание текста (кнопка со сканером): распознаёт текст на картинке и копирует его. Нужен tesseract.
  • Закрепить поверх окон: готовая картинка висит над всеми окнами.
  • Сохранить проектом .kadr (кнопка проекта): сохраняет файл .kadr со всей правкой в папку скриншотов, редактор остаётся открытым. См. Файлы проектов.
  • Копировать (Ctrl+C): кладёт готовую картинку в буфер обмена и закрывает редактор.
  • Размер экспорта: Исходный (собственные пиксели картинки), 1× (её размер на экране) или 2×. Действует на сохранение, копирование и перетаскивание.
  • Сохранить как… (Ctrl+Shift+S): в файл на ваш выбор. Формат задаёт расширение в имени: PNG, JPEG (белый там, где картинка прозрачна) или WebP (без потерь); имя на .kadr сохраняет проект.
  • Сохранить (Ctrl+S): записывает поверх открытого файла (JPEG остаётся JPEG), копирует его, закрывает редактор и показывает карточку результата.

В узком окне распознавание текста, закрепление, проект и копирование уходят в меню Ещё.

Запись

Записывает область или весь экран в MP4 — с микрофоном, звуком компьютера, камерой и сочетаниями клавиш, которые вы нажимаете. В режиме студии запись сразу открывается в студии, где из неё получается готовый ролик. Задачи помельче, обрезать запись или сделать GIF, решаются прямо с карточки после записи.

Как открыть

  • Горячая клавиша. На macOS и Windows по умолчанию Ctrl+Shift+2; на Linux kadr берёт ваши привязки из Hyprland. Для «Запись прошлой области» можно назначить свою клавишу в «Настройки» → «Клавиши».
  • Панель съёмки (kadr capture): «Запись» или 8. См. Съёмка.
  • Меню трея: «Запись экрана».
  • Команда kadr record. Если нажать горячую клавишу (или запустить kadr record) ещё раз, панель записи закроется, а идущая запись остановится.

Сначала выбирается область, так же, как для скриншота (см. Съёмка): протяните рамку, кликните по окну, чтобы записать его, или кликните по пустому месту, чтобы записать весь экран. Как только отпустите мышь, рядом с областью появится панель записи.

Панель записи

Панель стоит под областью (а если места нет — над ней или внутри неё), остальной экран затемнён. Слева направо:

  • «Отмена» (Esc).
  • «Размер области»: размер области в пикселях. По клику открывается меню размеров: 640 × 480, 1280 × 720, 1920 × 1080, 1080 × 1080, 1080 × 1920 или «Весь экран».
  • «Микрофон»: клик включает и выключает его. Пока он включён, кнопка заполняется снизу в такт громкости, так что видно, что вас слышно. Стрелка рядом выбирает микрофон (системный по умолчанию или другой).
  • «Звук системы»: то, что играет компьютер.
  • «Камера»: показывает пузырь камеры над областью (см. ниже).
  • «Сочетания клавиш»: записывает нажатые сочетания, чтобы студия показала их плашками.
  • «Режим студии»: включён по умолчанию, см. ниже.
  • «Отсчёт перед записью»: выключен, 3 или 5 секунд, поверх области. Esc во время отсчёта отменяет запись.
  • «Другая область» (R): выбрать область заново.
  • «Весь экран» (F): записать вместо области весь экран.
  • «Записать» (Enter).

Пока панель на экране, область можно править: тянуть за ручки на углах и сторонах, перетаскивать, взявшись изнутри, двигать стрелками или менять размер через Alt+стрелки. Панель запоминает выбранное до следующей записи.

Режим студии пишет запись для студии: системный курсор в видео не попадает, а kadr записывает, где был указатель, так что студия рисует свой курсор, крупный и плавный, и ставит зумы на ваши клики. Камера пишется отдельно. После остановки запись открывается в студии, а не на карточке.

Во время записи

Рядом с областью, за её пределами, остаётся маленькая панель, чтобы не попасть в запись. На ней красная точка и время, уровень микрофона и кнопки:

  • «Пауза» и «Продолжить»: время паузы в файл не попадает.
  • «Остановить и сохранить».
  • «Начать заново»: выбрасывает дубль и записывает ту же область ещё раз.
  • «Остановить и удалить».

Красная рамка отмечает записываемую область, остальной экран затемнён; ни то ни другое в запись не попадает, а клики проходят к окнам под ними. Выключается настройкой «Рамка вокруг области».

Когда записывается весь экран, панель уходит на другой монитор. Если монитор один, ставить её некуда: остановите запись горячей клавишей или командой kadr record stop.

Пузырь камеры

Включите «Камера» на панели записи, и над областью появится живая картинка с камеры. Настройте её до записи:

  • Перетащите: пузырь прилипает к углу или к середине стороны.
  • Наведите на него, чтобы появились «Меньше», «Больше» и «Форма». «Форма» перебирает круг, скруглённые углы и квадрат.
  • Размер меняется и колесом мыши над пузырём, и перетаскиванием ободка вокруг него.

kadr запоминает вид пузыря до следующей записи, и студия начинает с него. Без режима студии пузырь записывается там, где вы его поставили. В режиме студии камера пишется в отдельный файл, а форму, размер и место ей задаёт студия.

После записи

Без режима студии в углу экрана появляется карточка с длиной записи. По умолчанию файл копируется в буфер обмена, чтобы вставить его в чат или папку. Наведите на карточку, чтобы появились кнопки:

  • «Копировать»: файл в буфер обмена.
  • «Студия» открывает студию. Подсказка говорит, что получится: «Зумы по вашим кликам», если kadr их записал, или «Фон и зумы вручную», если нет.
  • «Обрезать» (справа вверху): окно обрезки, см. ниже.
  • GIF (справа внизу): «Сохранить как GIF», вся запись, 720 пикселей в ширину, 15 кадров в секунду.
  • «Показать в папке», «Удалить файл» (в корзину) и «Закрыть».

Двойной клик открывает запись в вашем видеоплеере. Перетащите карточку в чат или файловый менеджер, чтобы бросить туда файл. Пока делается GIF или обрезка, карточка показывает ход работы с кнопкой «Отменить», а потом становится карточкой результата.

Окно обрезки

Окно обрезки (kadr trim) показывает кадр видео над лентой кадров. Тяните на ленте ручки начала и конца; клик переносит туда ближайшую из них. Кадр сверху меняется вслед, а «Выбрано» показывает длину.

  • «Проиграть» (Пробел) проигрывает выбранный кусок в mpv.
  • «Сохранить» (Ctrl+S, на macOS Cmd+S) вырезает его в новый файл с «-trim» в имени; кнопка работает, когда что-то обрезано. Оригинал остаётся.
  • «Сохранить GIF» (G) делает GIF из выбранного куска: 480, 720 или 960 пикселей в ширину, 10, 15 или 24 кадра в секунду.
  • «Отмена» (Esc).

kadr trim <video> --from S --to S обрезает без окна, а kadr gif <video> делает GIF из всей записи, 720 пикселей в ширину, 15 кадров в секунду.

На macOS и Windows

Запись там идёт через системный захват и кодировщик, со звуком системы и микрофоном по умолчанию. Выбор другого микрофона, его индикатор громкости и камера пока есть только на Linux. Лог кликов и клавиш тоже: его пишет хук Hyprland, поэтому зумы по кликам студия ставит только на Linux. Живьём на Mac или Windows ещё никто не записывал.

Студия

Студия превращает запись экрана в готовый ролик: приближает там, где вы кликали, вырезает скучные куски, рисует крупный плавный курсор, кладёт видео на фон с камерой в углу и выдаёт MP4 или GIF.

Лучше всего она работает с записью в режиме студии (кнопка-искра на панели записи): тогда системный курсор не попадает в видео, kadr рисует свой, а камера пишется отдельно, и всё это можно менять здесь. См. Запись.

kadr сохраняет правку на ходу: откройте ту же запись снова, и всё на месте. Изменено рядом с именем в заголовке значит, что правка есть. Проект сохраняет запись вместе с правкой в файл .kadr рядом с записями (см. Файлы проектов).

Как открыть

  • Из карточки после записи: Студия.
  • После записи в режиме студии она открывается сама.
  • После каждой записи: включите Настройки → Запись → Открывать студию.
  • Из истории: выберите запись и нажмите E или кнопку Студия.
  • Из командной строки: kadr studio <video|project.kadr>. С --render kadr сразу экспортирует ролик с сохранённой правкой, не открывая окна.
  • Из файлового менеджера: проект .kadr с записью открывается в студии.

Окно

  • Слева полоса разделов: Зум, Курсор, Сочетания клавиш, Звук, Камера, Фон и отдельно внизу Вырезка. По щелчку рядом с полосой открываются настройки раздела.
  • В середине сцена: видео играет так, как будет выглядеть, со всеми эффектами.
  • Внизу таймлайн: линейка, раскадровка, под ней дорожка зумов и в самом низу строка вырезок. Щелчок по линейке или раскадровке переносит плейхед. Над таймлайном: В начало, воспроизведение и пауза, В конец и две кнопки Масштаб таймлайна.
  • В заголовке: имя файла, Проект и Экспорт.

Зумы и вырезки

Зум. В записи из режима студии зумы уже расставлены по вашим кликам; в любую другую добавьте их сами.

  • Щелчок по дорожке зумов добавляет зум. Зум можно перетащить, а за края растянуть или сжать.
  • Масштаб задаёт, насколько близко подходит выбранный зум (от 100% до 400%); Применить ко всем зумам даёт всем тот же масштаб.
  • Режим зума у выбранного зума: За курсором или Вручную, и тогда щёлкните по видео, куда приблизить.
  • Удалить зум (или Delete) убирает выбранный.
  • Автоматически → Зумы по кликам заново расставляет зумы по кликам вместо тех, что были. Нужна запись с кликами.
  • Размытие в движении: Выкл, Слабое или Сильное, при зумах, сдвигах камеры и быстром курсоре. Видно в предпросмотре и экспорте.

Вырезка.

  • Жёлтые края раскадровки обрезают начало и конец.
  • Протяните по строке вырезок, и этот кусок вырежется. Вырезку можно перетащить, а её края подвинуть. X вырезает секунду у плейхеда.
  • Когда вырезка выбрана, раздел Вырезка показывает, что она убирает; Вернуть кусок (или Delete) возвращает его. Вернуть всё видео снимает обрезку и все вырезки.

Курсор, сочетания, камера и звук

Курсор:

  • Для записи в режиме студии: Показывать курсор, его Размер (от 0,5× до 3×), Вид (Стрелка, Светлая стрелка или Точка) и Движение (Естественное или Плавное). В остальных записях курсор остаётся таким, каким записался.
  • Клики: Волны от кликов (кольца там, где вы кликали), а с курсором kadr ещё Эффект нажатия (курсор откликается на клик).

Сочетания клавиш: Показывать сочетания выводит на видео плашку с нажатыми сочетаниями, Снизу или Сверху, размером S, M или L. Нужна запись, сделанная с включёнными Сочетаниями клавиш на панели записи.

Камера (если она есть в записи): Показывать камеру, её Размер, Скругление от квадрата до круга и место: одно из восьми по краям.

Звук (если он есть в записи): Звук вкл. или выкл., Громкость (до 200%), Каналы: Стерео или Моно. В GIF звука не бывает.

Фон и экспорт

Фон:

  • Пресеты наверху: + сохраняет текущий вид (фон, отступы, курсор, экспорт), в выпадающем списке пресет выбирают, переименовывают или удаляют.
  • Градиенты, Обои (фоны тем Omarchy, если они есть, и Своя картинка…) и Цвет.
  • Пропорции: Авто (как у записи), 1:1, 5:4, 4:3, 3:2, 16:9 и вертикальные 4:5, 3:4, 9:16.
  • Отступ, Углы и Тень.

Экспорт. Кнопка Экспорт открывает настройки экспорта:

  • Формат: MP4 или GIF.
  • Размер: 720p, 1080p, 1440p или 4K.
  • Кадры: Как есть (как записано), 30, 60 или 120.
  • Сжатие (только для MP4): Лучшее, Высокое, Среднее или Маленький.
  • Под ними размер и длина ролика и сколько примерно займёт файл.
  • Предпросмотр собирает быстрый ролик в 720p со всеми эффектами и показывает его в mpv. Экспорт (или Ctrl+S) закрывает студию и делает ролик, он ложится рядом с записью, к имени добавляется -studio. Ход экспорта виден на карточке поверх размытого кадра, там же кнопка отмены, а потом карточка становится результатом.

Новая запись начинается с вида, который вы использовали в студии последним.

История

Все скриншоты, записи и GIF из ваших папок для скриншотов и записей, сначала новые, сеткой миниатюр. Найдите нужное, набрав пару букв, и откройте, скопируйте, закрепите, удалите или вытащите файл в чат.

Как открыть

  • Горячая клавиша. На macOS и Windows по умолчанию Ctrl+Shift+4; на Linux kadr берёт ваши привязки из Hyprland. Назначается в «Настройки» → «Клавиши» → «История».
  • Команда kadr history.

Поиск

По истории ходят в основном набором текста: просто начните печатать, кликать в поле не нужно. Поиск ищет по имени файла и по дате в том виде, как она подписана под миниатюрой: «сегодня», «вчера», «12 окт». Backspace стирает букву, Esc очищает поиск.

Под каждой миниатюрой день и время (у снимков прошлых лет вместо времени год) и тип: PNG, MP4 или GIF. На миниатюре записи видна её длина.

Фильтры наверху показывают что-то одно и сколько этого: «Все», «Скриншоты», «Записи» и GIF. Tab переключает их по кругу. В узком окне они сворачиваются в выпадающий список.

История показывает 300 последних снимков и записей. Если ничего не нашлось, она пишет «Ничего не найдено», а если ещё ничего не снято — «Пока ничего не снято».

Выбор

Текущая миниатюра обведена цветной рамкой. Её можно двигать стрелками или выбрать кликом.

  • Ctrl+клик добавляет миниатюру к выбранным или убирает её (на macOS Cmd+клик).
  • Shift+клик выбирает всё от текущей миниатюры до той, по которой кликнули.
  • Ctrl+A выбирает все показанные.

Когда выбрано несколько, нижняя панель пишет сколько, а копирование, удаление и закрепление работают со всеми сразу. Esc снимает выбор.

Действия

  • «Открыть» (Enter или двойной клик): скриншот открывается в редакторе, запись в студии, GIF в системном просмотрщике.
  • «Редактор / студия» (E): то же, для скриншота или записи.
  • «Копировать» (Ctrl+C): один скриншот попадает в буфер обмена картинкой, а запись, GIF или несколько файлов — файлами. Окно закрывается.
  • «Закрепить» (P): закрепляет выбранные скриншоты поверх всех окон (см. Съёмка).
  • «Удалить» (Del): отправляет выбранное в корзину.

Если навести на миниатюру, те же действия появятся кнопками: «Копировать» и «Редактировать» (для записи «Студия») посередине, «Показать в папке» справа вверху, «Удалить» справа внизу и, у скриншота, «Закрепить поверх окон» слева внизу.

Перетащите миниатюру в чат, браузер или файловый менеджер, чтобы бросить туда файл.

Шестерёнка справа вверху открывает настройки. Нижняя панель подсказывает клавиши, а в узком окне убирает те, что нужны реже.

Хранилище

«Занято» показывает место и число файлов по категориям «Скриншоты», «Записи» и «Кэш студии». В «Удалять старые снимки и записи» можно выбрать «Никогда», 7, 30 или 90 дней. Включённая автоочистка запускается не чаще раза в день и навсегда удаляет старые снимки и записи kadr, не трогая остальные файлы в этих папках.

Сначала выберите срок, затем нажмите «Очистить сейчас → Очистить», чтобы применить его сразу. Результат сообщает освобождённое место и число файлов. В файле за это отвечает cleanup_days; 0 отключает автоматическое удаление. Очистка также убирает данные правки, исходный снимок или запись которых уже удалены.

Файл настроек

Настройки хранятся в settings.toml, на Linux — в ~/.config/kadr. Откройте «Настройки → О kadr → Файл настроек → Изменить», чтобы править его в системном редакторе. «Показать в папке» открывает его папку.

Правки руками подхватываются, когда kadr в следующий раз понадобится настройка. Окно сохраняет комментарии и порядок строк, меняя только значения, которые вы поменяли в нём. Пропущенная настройка берётся по умолчанию; нечитаемое значение игнорируется. Если TOML-файл сломан, kadr берёт настройки по умолчанию, показывает место ошибки в окне настроек и оставляет файл как есть. До исправления изменения в окне не сохраняются. Старый settings.json переносится автоматически и переименовывается в settings.json.old.

Файлы проектов

Проект .kadr хранит правку, а не только готовую картинку или видео. Его можно открыть позже или перенести на другой компьютер и продолжить работу.

Как открыть

kadr open <file> открывает проект в редакторе или студии в зависимости от содержимого. kadr edit <image|project.kadr> открывает проект скриншота; kadr studio <video|project.kadr> — проект записи.

Файл .kadr можно открыть и из файлового менеджера, когда тип файлов зарегистрирован. На Linux kadr делает это при первом запуске; kadr install-desktop повторяет настройку. Установщик Windows регистрирует связь с приложением. Подробнее — в установке.

Сохранение

Нажмите «Проект» в редакторе или студии, чтобы сохранить исходную картинку или запись вместе с правкой. Проект скриншота хранит все фигуры; проект записи — зумы, вырезки и обрезку вместе с остальными настройками студии.

После открытия проекта сохранение перезаписывает тот же файл .kadr. В редакторе «Сохранить» тоже обновляет открытый проект; в студии «Экспорт» обновляет его перед сборкой видео. Если нужна предыдущая правка, сначала оставьте отдельную копию.

Что внутри

Проект — tar-архив, в котором вместе лежат исходные материалы и сведения о правке:

  • Проект скриншота хранит исходную картинку, добавленные изображения, разметку и превью. Чёрные плашки навсегда убирают закрытое ими и из редактируемого исходника.
  • Проект записи хранит видео, лог кликов, клавиш и курсора, монтаж студии, а также отдельную запись камеры и обои, если они есть.

При открытии проект распаковывается в кэш kadr. Самим распаковывать его или держать исходники рядом не нужно.

Скриншоты

kadr capture открывает панель со всеми режимами съёмки. kadr shot по умолчанию запускает умный выбор; явно можно выбрать область, окна, экран, все экраны, таймер или прошлую область. kadr shot scroll начинает снимок с прокруткой и завершает его при повторном вызове. kadr open <file> показывает существующую картинку на карточке; kadr pin <file> закрепляет её поверх окон. Подробнее — в съёмке.

Запись

kadr record открывает панель записи или останавливает текущую запись. Варианты region и fullscreen начинают сразу; можно включить микрофон, звук системы, камеру, показ сочетаний и режим студии. Варианты area и previous открывают панель для заданной или прошлой области. kadr record stop явно останавливает запись. Подробнее — в записи; лог кликов и клавиш через Hyprland работает только на Linux.

Редактирование

kadr edit <image|project.kadr> открывает редактор; kadr studio <video|project.kadr> — студию, а флаг render сразу запускает экспорт. kadr open <file> открывает проект в нужном редакторе. kadr trim <video> открывает обрезку или обрезает сразу по времени в секундах; для начала нужно задать и конец. kadr gif <video> делает GIF размером 720px с частотой 15 кадров в секунду. Как сохранить правку — в файлах проектов.

Остальные команды

kadr history открывает историю, kadr settings — настройки. kadr text [image] распознаёт текст на картинке или предлагает выбрать область и копирует результат. kadr update проверяет новый релиз сразу; kadr tray запускает трей для автозапуска. kadr install-desktop регистрирует файлы проектов на Linux. kadr --version печатает версию. Команда для разработки предназначена для тестовых хуков, а не для обычной съёмки.
