kadr manual

kadr

Screenshots and screen recording for the desktop: capture an area, a window or the screen, annotate it, record with your camera and clicks, and turn a recording into a polished video. Written in Rust on GPUI CE. Made first for Linux on Omarchy (Arch, Hyprland, Wayland), coming to macOS and Windows. English and Russian; dark and light themes follow the system.

This manual says what kadr does today, screen by screen. Each page has the same shape: what the screen is for, how to open it, what's on it, its keys, the settings that change it and the commands that start it. What changed between versions is in the changelog; where the project is going is the roadmap (in Russian).

Platforms

  • Linux (Wayland, Hyprland): everything works, and this is where kadr is used every day.
  • macOS and Windows: the editor, the studio, screenshots (window and scrolling shots too), recording through the system's capture, the clipboard, notifications, the tray, global hotkeys and the area overlay are written and pass the end-to-end test on CI's runners. The camera, choosing a microphone and the studio's click and key log aren't ported yet, and nobody has run kadr on a real machine there: testers are very welcome.

Help

Bugs and questions go to GitHub issues. A crash leaves crash.log in kadr's cache folder; attach it. Developers start at CONTRIBUTING.md.

Install

Use a release build, or build kadr from source with Rust 1.95 or newer. Linux on Wayland with Hyprland is the main platform.

Downloads

Releases has a Linux .tar.xz with INSTALL.md, a macOS .dmg containing Kadr.app for Apple silicon or Intel, and a Windows installer or portable .exe.

The builds are not signed yet. After copying the macOS app to Applications, run:

xattr -dr com.apple.quarantine /Applications/Kadr.app

Linux (Hyprland)

Install gpu-screen-recorder, ffmpeg, tesseract with English language data, grim and wl-clipboard. On Omarchy they may already be installed; otherwise use pacman. mpv is optional: the trim window's Play and the studio's Preview play through it.

To build from source and install the two programs:

cargo build --profile dist -p kadr -p kadr-tray
install -m755 target/dist/kadr target/dist/kadr-tray ~/.local/bin/

Copy the Hyprland hook from the source tree:

cp data/hypr/kadr.lua ~/.config/hypr/kadr.lua

Add require("hypr.kadr") to ~/.config/hypr/hyprland.lua. The hook floats kadr's windows, loads the shortcuts saved in Settings, and logs clicks and shortcut keys while recording for the studio. Linux starts with your existing Hyprland bindings, not the global defaults used on the other systems.

Start kadr-tray at login. In Omarchy's autostart.lua, add:

o.launch_on_start("kadr-tray")

On its first run, kadr registers the .kadr project file type, icon and menu entry on Linux. Run kadr install-desktop to do it by hand.

macOS and Windows

For a source build, build all three programs and keep kadr, kadr-tray and kadr-overlay side by side:

cargo build --profile dist -p kadr -p kadr-tray -p kadr-overlay

The tray holds the global shortcuts, so start kadr-tray at login. The defaults and how to change them are in Settings. The Windows installer sets up the tray at login and the .kadr file association; the portable build is a single kadr.exe.

Unsigned builds are also attached to manually started Actions runs. For those standalone macOS programs, remove quarantine before opening them:

xattr -d com.apple.quarantine kadr kadr-tray kadr-overlay

Screenshots, window shots, the editor, studio and recording through the system's capture are implemented on macOS and Windows. Scrolling screenshots are available there too. These systems have CI tests, but have not yet been tried on a real machine. The Hyprland click/key log is Linux-only.

Updating

With General → Check for updates on in Settings, the tray checks once a day. A new release appears on an update card. Release page opens its notes and downloads; Update downloads the release, verifies its release signature and replaces the installed files. The tray restarts on the new version. A version that fails to start three times in a row is replaced by the previous one. Package-manager installations are updated through their manager instead.

Choose Update channel in General: Stable gets finished versions only; Beta also gets alpha, beta and release-candidate versions. A pre-release build uses Beta until you change it.

To check immediately, open Settings → About kadr → Check now. The same row shows the result and offers the update. kadr update shows the result on a card instead.

Commands

  kadr settings                                  settings
  kadr update                                    look for a newer release now
  kadr tray                                      tray icon (for autostart)
  kadr install-desktop                           let .kadr project files open in kadr (file type, icon, menu entry)

kadr install-desktop is Linux-only. See Command line for all commands.

Capture

Everything that takes a picture of the screen: an area, a window, the whole screen or every screen, a long scrolling shot, a shot on a self-timer. After a capture a card shows in the corner of the screen, where you copy the picture, open it in the Editor, pin it on top of your windows or read the text in it. Text recognition and pinning live here too.

How to open

  • The capture bar (kadr capture) puts every mode on one bar, so one hotkey is enough. It has no default hotkey: set one in Settings → Shortcuts → All modes on one bar.
  • Hotkeys. On macOS and Windows the defaults are Ctrl+Shift+1 for an area, Ctrl+Shift+3 to recognize text and Ctrl+Shift+6 for a scrolling screenshot. On Linux kadr starts from your Hyprland bindings. More actions (the previous area, a window or area, the screen) can get a hotkey in Settings → Shortcuts.
  • The tray menu: Screenshot, Recognize text, Scrolling screenshot.
  • Commands: kadr shot, kadr shot scroll, kadr text, kadr pin; see Commands.

The capture bar

The bar shows near the bottom of the screen with eight modes in three groups:

Click a mode, press its digit, or move with the left and right arrows and press Enter. Esc, a click outside the bar or the same hotkey again closes it.

Picking an area

The screen freezes, and you drag a box over it. A hint bar says what the keys do at each moment.

  • Drag to draw the area; it's taken when you let go. Shift while dragging makes a square. Holding Space while dragging moves the whole box instead.
  • Click without dragging: over a window it takes that window; over nothing it copies the colour under the pointer as a hex code (#RRGGBB) and kadr says "Color copied".
  • Space switches to windows only: a click takes the window under the pointer, and nothing is drawn. Space again goes back to drawing an area.
  • Keep the area to adjust it. Press an arrow, A or P, or a digit, while the box is there, and it stays after you let go of the mouse. Then drag its handles to resize it, drag it from inside to move it, or double-click inside it to take it.
  • Arrows move the area a pixel, Shift+arrows ten. Alt+arrows grow or shrink it from the right and bottom edges.
  • A steps through aspect ratios: Free, 1:1, 4:3, 16:9, 9:16.
  • Digits type an exact size in screen pixels: the width, then X (or Tab or Space) and the height, then Enter. Left without a height, it follows the aspect ratio.
  • P brings back the last area picked on this screen, to adjust. Enter with nothing drawn takes that area straight away.
  • Enter takes the area; Esc cancels.

The Area mode and kadr shot region don't snap to windows: a click there only copies a colour.

Windows, screens and scrolling

  • A window comes by itself, whatever covers it, with rounded corners and a soft shadow on a transparent background. Window shadow in the settings turns the shadow off. Window background puts it straight onto a background saved in the editor instead; the editor opens it with that background, still to change. Window shots work on Linux, macOS and Windows.
  • Fullscreen takes the screen the focus is on.
  • Every screen at once (kadr shot all): all monitors in one picture, laid out as your desktop has them.
  • The self-timer counts 3, 5 or 10 seconds over the screen (Self-timer in the settings), then takes it. Esc cancels the countdown.
  • The pointer can be in the picture: turn on Pointer in screenshots.

A scrolling shot: pick an area, then scroll it yourself. kadr keeps grabbing the area and stitches what comes into view into one long picture. It works down a page and sideways, to the right (a timeline, a wide table), which makes one wide picture.

A frame shows round the area, and a bar by it says "Scroll — kadr stitches it" with the length so far in pixels. Press Done, or the same hotkey again, to save it; Cancel throws it away. Scrolling shots work on Linux, macOS and Windows.

The card after a capture

A card with the picture slides in at the corner of the screen. By default the screenshot is also copied to the clipboard right away. Hover over the card for its buttons:

  • Copy: puts the picture on the clipboard and closes the card.
  • Edit: opens it in the Editor. A double-click on the card does the same.
  • Pin on top (top right): keeps it above every window, see below.
  • Recognize text (bottom right): reads the text in the picture.
  • Show in folder (bottom right).
  • Delete file (bottom left): moves the file to the trash.
  • Close (top left).

Drag the card into a chat, a browser or a file manager to drop the file there. Swipe it toward the screen edge to put it away.

A card goes after 10 seconds by default, and stays while the pointer is over it. How long, which corner and how many cards at once are in Settings → General.

Pinning

A pinned picture floats above every window, at its real size, so you can keep a reference in sight while you work. Pin a screenshot from its card, from the editor's bottom bar, from History (P), with kadr pin, or have every screenshot pinned (Pin on top under After a screenshot).

  • Drag it to move it; arrows nudge it a pixel, Shift+arrows ten.
  • Scroll to zoom it; Alt+scroll or Ctrl+scroll changes its opacity.
  • L lets clicks through to the windows below it. Only the lock in its corner still takes clicks; press it, or L, to catch clicks again.
  • Esc, a double-click or a right-click closes it.

Text recognition

kadr text freezes the screen; pick an area, and its text goes to the clipboard. A card shows what was found, with Copy again and, when the text holds a link, Open link. QR codes are read too, when zbar is installed. With a picture (kadr text <image>, or Recognize text on a card) kadr reads the whole picture.

kadr reads English and Russian, and Ukrainian, German, French and Spanish too when Tesseract has them. Russian needs Tesseract's Russian data: on Arch it's the tesseract-data-rus package, or Settings → Text → Russian downloads it (15 MB) into kadr's own folder, without sudo.

Editor

The editor is where a screenshot gets its arrows, boxes, text and step numbers, where private details are hidden, and where the picture is cropped and put on a background. What you draw stays editable: open the saved file in the editor again and every shape comes back.

It opens PNG, JPEG and WebP pictures, and .kadr project files.

How to open

  • From the card after a screenshot: Edit.
  • Right after every screenshot: turn on Settings → Screenshots → Open the editor.
  • From History: select a screenshot and press E, or click Edit.
  • From the command line: kadr edit <image|project.kadr>. kadr open with a .kadr file opens its project too.
  • From the file manager: .kadr files open in kadr (see Project files).

On Linux the editor opens as an ordinary window by default; it can cover the whole screen instead (see Settings below). On macOS and Windows it's always a window.

Tools

The tools sit in the top bar, in groups. Each has a letter; the tooltip says the tool's name. When the window is narrow, the last tools fold under More tools.

Hide is built to stay hidden: the blur and the pixelation are mixed with noise so the text can't be brought back, and with the black box what's under it is gone from the saved file altogether. With the hide tool picked, Hide sensitive in the top bar finds e-mails, keys, card and phone numbers in the picture and covers each one the way picked; one undo takes them all off. It reads the picture with tesseract, which has to be installed.

Colour, size and a shape's options

  • Colour and size stay in the top bar's corner. They apply to the next shape, and to the selected one.
  • The colour menu has kadr's eight colours (keys 1–8), the pipette (I: click the picture to take a colour from it), Recent colours, and Yours: + keeps the current colour there, right-click one to remove it.
  • A shape's own options float in a bar under the selected shape: an arrow's style, a box's fill, a text's style, how an area is hidden, a pointer's look. An arrow, a box, an ellipse or a hidden area stays selected after you draw it, so its bar is right there. The next shape takes what you picked last.
  • Undo and redo are in the top bar too.

Background and presets

The background button in the top bar opens a sidebar:

  • Presets at the top: + saves the current look as a preset, the dropdown picks one, and each can be renamed or deleted from there.
  • None, Gradients (Show more for the rest), Wallpapers (the Omarchy themes' backgrounds, where there are any, plus Your own image…), Blurred (the screenshot itself, blurred), Plain color (including Transparent).
  • Padding, Corners and Shadow sliders.
  • Aspect ratio: Auto, 16:9, 4:3, 1:1 or 9:16. The final size shows under it.
  • Position: where the picture sits on a 3×3 grid. Off the middle it sits flush with that edge or corner. Even margins trims the screenshot's plain margins to match, so what's in it sits in the middle.

Pictures can be added to a screenshot:

  • dropped on the screenshot, or pasted with Ctrl+V, or picked with Add a picture on top, a picture goes on top as a shape;
  • dropped past the screenshot's edge, it joins the screenshot on that side, as tall (or as wide) as it. While you drag, the editor shows where it will go. On a background, the joined pictures make one card with one shadow.

Crop

C (or the crop button in the top bar) opens the crop mode. Drag the crop's edges and corners; they snap to edges in the picture while Snap to edges is on (hold Ctrl to do the opposite for a moment). Its top bar:

  • Aspect ratio: Freeform, Original, 1:1, 16:9, 9:16, 4:3, 3:2, 4:5, 21:9.
  • Width and height in pixels: click one and type; Tab moves to the other.
  • Swap width and height, Rotate 90° clockwise, Flip horizontally.
  • Fill past the picture: a crop can reach past the picture; this picks what fills that room (transparent, white, black or a pen colour).
  • Image size: save a smaller picture: 100%, 75%, 50%, 33% or 25%.
  • Cancel and Crop.

At the bottom: the zoom, Snap to edges and Revert to Original. Once cropped, Uncrop in the editor's bottom bar brings the whole picture back.

The canvas and the bottom bar

The canvas zooms: Ctrl and the mouse wheel zoom at the pointer, the wheel alone or Space with a drag pans. The zoom menu at the bottom left has Fit, 25%, 50%, 100% and 200%. A file reopened with its drawing gets Start over there, to go back to the clean picture.

The bottom bar, left to right:

  • Drag: drag the finished picture into a chat or a folder.
  • Text recognition (the scan button): recognizes the text in the picture and copies it. It needs tesseract.
  • Pin on top of the windows: the finished picture floats above every window.
  • Save as a .kadr project (the project button): saves a .kadr file with the whole edit in the screenshots folder, and the editor stays open. See Project files.
  • Copy (Ctrl+C): puts the finished picture on the clipboard and closes the editor.
  • Export size: Original (the picture's own pixels), 1× (its size on screen) or 2×. It applies to saving, copying and dragging.
  • Save as… (Ctrl+Shift+S): a file of your choice. The name's extension picks the format: PNG, JPEG (white where the picture is transparent) or WebP (lossless); a name ending in .kadr saves a project.
  • Save (Ctrl+S): writes over the file you opened (a JPEG stays a JPEG), copies it, closes the editor and shows the result's card.

When the window is narrow, text recognition, pinning, the project and copying fold into a More menu.

Settings

  • Open the editor (Settings → Screenshots → After a screenshot): open every new screenshot in the editor. In settings.toml: after_shot.edit.
  • Editor (Settings → Screenshots, Linux only): Window, or Over everything to cover the screen. In settings.toml: editor_window.

Recording

Records an area or the whole screen to an MP4, with the microphone, the computer's sound, your camera and the shortcuts you press. In studio mode the recording opens straight in the Studio, which turns it into a finished video. Smaller jobs, trimming and making a GIF, are done right from the card after a recording.

How to open

  • The hotkey. On macOS and Windows the default is Ctrl+Shift+2; on Linux kadr starts from your Hyprland bindings. Record the previous area can get a hotkey of its own in Settings → Shortcuts.
  • The capture bar (kadr capture): Recording, or 8. See Capture.
  • The tray menu: Record the screen.
  • The command kadr record. Pressing the hotkey (or running kadr record) again closes the recording bar, or stops a recording that's running.

First you pick the area, the same way as for a screenshot (see Capture): drag a box, or click a window to record it, or click elsewhere to record the whole screen. The recording bar then shows by the area as soon as you let go of the mouse.

The recording bar

The bar sits under the area (or above it, or inside it, where there's no room), and the rest of the screen is dimmed. From the left:

  • Cancel (Esc).
  • Area size: the area's size in pixels. Click it for a menu of sizes: 640 × 480, 1280 × 720, 1920 × 1080, 1080 × 1080, 1080 × 1920, or Fullscreen.
  • Microphone: a click turns it on or off. While it's on, the button fills from the bottom with how loud you are, so you can see you're heard. The arrow beside it chooses the microphone (the system's default, or another one).
  • System audio: what the computer plays.
  • Camera: shows the camera bubble over the area (see below).
  • Keyboard shortcuts: logs the shortcuts you press, for the studio to show as badges.
  • Studio mode: on by default, see below.
  • Countdown before recording: off, 3 or 5 seconds, counted over the area. Esc during the count cancels.
  • Another area (R): pick the area again.
  • Fullscreen (F): record the whole screen instead.
  • Record (Enter).

The area stays adjustable while the bar is up: drag the knobs on its corners and edges, drag it from inside, move it with the arrows, or resize it with Alt+arrows. The bar remembers its choices for the next recording.

Studio mode records for the Studio: the system cursor stays out of the video, and kadr logs the pointer, so the studio draws its own cursor, large and smooth, and places zooms on your clicks. The camera is recorded separately. When you stop, the recording opens in the studio instead of showing a card.

While recording

A small bar stays by the area, outside it, so it isn't recorded. It shows a red dot and the time, the microphone's level, and:

  • Pause and Resume: the paused time is left out of the file.
  • Stop and save.
  • Start over: throws the take away and records the same area again.
  • Stop and delete.

A red frame marks the recorded area and the rest of the screen is dimmed; neither is recorded, and clicks go through to the windows below. Frame around the area in the settings turns this off.

When the whole screen is recorded, the bar goes to another monitor. With only one monitor there's nowhere to put it: stop with the hotkey, or kadr record stop.

The camera bubble

Turn on Camera in the recording bar, and a live picture of your camera shows over the area. Set it up before recording:

  • Drag it: it snaps to a corner or to the middle of an edge.
  • Hover over it for Smaller, Bigger and Shape. Shape steps through a circle, rounded corners and a square.
  • Scroll over it, or drag the band round it, to resize it.

kadr remembers the look for the next recording, and the studio starts from it. Without studio mode the bubble is recorded where you put it. In studio mode the camera goes to a file of its own, and the studio shapes, sizes and places it.

After recording

Without studio mode a card shows in the corner of the screen, with the recording's length. The file is copied to the clipboard by default, to paste into a chat or a folder. Hover over the card for:

  • Copy: the file, to the clipboard.
  • Studio: opens the Studio. Its tooltip says what you'll get: "Zooms follow your clicks" when kadr logged them, "Background and zooms by hand" when it didn't.
  • Trim (top right): the trim window, below.
  • GIF (bottom right): Save as GIF, the whole recording, 720 pixels wide at 15 fps.
  • Show in folder, Delete file (to the trash) and Close.

A double-click opens the recording in your video player. Drag the card into a chat or a file manager to drop the file there. While a GIF or a trim is being made, a card shows its progress, with Cancel, and then turns into the result's card.

The trim window

The trim window (kadr trim) shows a frame of the video over a filmstrip. Drag the start and end handles on the filmstrip; a click moves the nearer one there. The frame follows, and "Selected" shows the length.

  • Play (Space) plays the selected piece in mpv.
  • Save (Ctrl+S, Cmd on macOS) cuts it into a new file with "-trim" in its name; it works once something is trimmed. The original stays.
  • Save GIF (G) makes a GIF of the selected piece: 480, 720 or 960 pixels wide, at 10, 15 or 24 fps.
  • Cancel (Esc).

kadr trim <video> --from S --to S trims without the window, and kadr gif <video> makes a GIF of the whole recording, 720 pixels wide at 15 fps.

On macOS and Windows

Recording there goes through the system's own capture and encoder, with the system's sound and the default microphone. Choosing another microphone, its level meter and the camera are Linux-only for now. So is the click and key log, which comes from the Hyprland hook: the studio places zooms on clicks only on Linux. Nobody has recorded on a real Mac or Windows machine yet.

Studio

The studio turns a screen recording into a finished video: it zooms in where you clicked, cuts out the dull parts, draws a large smooth cursor, puts the video on a background with the camera in a corner, and exports MP4 or GIF.

It works best with a recording made in studio mode (the sparkle button on the recording bar): then the system's cursor stays out of the video, kadr draws its own, and the camera is recorded separately, so all of them can be changed here. See Recording.

kadr keeps your edit as you go: open the same recording again and it's all there. Edited next to the name in the title bar says it's changed. Project saves the recording with its edit as a .kadr file, next to the recordings (see Project files).

How to open

  • From the card after a recording: Studio.
  • After a studio mode recording the studio opens by itself.
  • After every recording: turn on Settings → Recording → Open the studio.
  • From History: select a recording and press E, or click Studio.
  • From the command line: kadr studio <video|project.kadr>. With --render kadr exports right away with the saved edit, without opening the window.
  • From the file manager: a .kadr project of a recording opens in the studio.

The window

  • The rail at the left has the sections: Zoom, Cursor, Keyboard shortcuts, Audio, Camera, Background, and Cut apart at the bottom. A click opens a section's settings beside the rail.
  • The stage in the middle plays the video as it will look, with every effect.
  • The timeline at the bottom: the ruler, the filmstrip, the zoom track under it and the cut row at the very bottom. A click on the ruler or the filmstrip moves the playhead. Above it: To the start, play and pause, To the end, and two Timeline zoom buttons.
  • The title bar: the file's name, Project and Export.

Zooms and cuts

Zoom. A studio mode recording comes with zooms already placed on your clicks; for any other recording, add them yourself.

  • Click the zoom track to add a zoom. Drag a zoom to move it, drag its edges to make it longer or shorter.
  • Zoom level sets how close the selected zoom gets (100% to 400%); Apply zoom level to all gives every zoom the same level.
  • Zoom mode of the selected zoom: Follow cursor, or Manual: then click the video where to zoom.
  • Delete zoom (or Delete) removes the selected one.
  • Automatic → Zooms on clicks places zooms on the clicks again, in place of the ones there. It needs a recording with clicks.
  • Motion blur: Off, Light or Strong, on zooms, camera moves and a fast cursor. It shows in the preview and the export.

Cut.

  • The filmstrip's yellow edges trim the start and the end.
  • Drag across the cut row to cut that piece out. Drag a cut to move it, drag its edges to change it. X cuts a second at the playhead.
  • With a cut selected, the Cut section says what it removes; Restore the piece (or Delete) brings it back. Restore the whole video drops the trim and every cut.

Cursor, shortcuts, camera and audio

Cursor:

  • For a studio mode recording: Show the cursor, its Size (0.5× to 3×), Style (Arrow, Light arrow or Dot) and Motion (Natural or Smooth). Any other recording keeps the cursor as it was recorded.
  • Clicks: Ripple animation (rings where you clicked), and with kadr's own cursor, Press effect (the cursor reacts to a click).

Keyboard shortcuts: Show shortcuts puts a badge with the shortcuts you pressed on the video, at the Bottom or the Top, in size S, M or L. It needs a recording made with Keyboard shortcuts on in the recording bar.

Camera (when the recording has one): Show the camera, its Size, Rounding from a square to a circle, and where it sits: one of eight spots round the edge.

Audio (when the recording has sound): Audio on or off, Volume (up to 200%), Channels: Stereo or Mono. GIFs have no audio.

Background and export

Background:

  • Presets at the top: + saves the current look (background, padding, cursor, export), the dropdown picks, renames or deletes one.
  • Gradients, Wallpapers (the Omarchy themes' backgrounds, where there are any, plus Your own image…) and Plain color.
  • Aspect ratio: Auto (the recording's own), 1:1, 5:4, 4:3, 3:2, 16:9, and the tall 4:5, 3:4, 9:16.
  • Padding, Corners and Shadow.

Export. The Export button opens the export settings:

  • Format: MP4 or GIF.
  • Size: 720p, 1080p, 1440p or 4K.
  • FPS: Source (as recorded), 30, 60 or 120.
  • Quality (MP4 only): Best, High, Medium or Small.
  • Under them, the video's size and length and how big the file will be.
  • Preview builds a quick 720p video with every effect and plays it in mpv. Export (or Ctrl+S) closes the studio and makes the video, saved next to the recording with -studio added to its name. Its progress shows on a card over a blurred frame, with a cancel button, and the card becomes the result.

A new recording starts with the look you used last in the studio.

History

Every screenshot, recording and GIF in your screenshots and recordings folders, newest first, as a grid of thumbnails. Find one by typing, then open, copy, pin or delete it, or drag it out into a chat.

How to open

  • The hotkey. On macOS and Windows the default is Ctrl+Shift+4; on Linux kadr starts from your Hyprland bindings. Set it in Settings → Shortcuts → History.
  • The command kadr history.

Finding a capture

Typing is the main way through the history: just start typing, there's no field to click. The search matches the file's name and its date as the tiles show it, such as "today", "yesterday" or "12 Oct". Backspace takes a letter back; Esc clears the search.

Under each thumbnail are its day and time (a capture from an earlier year shows the year instead) and its kind: PNG, MP4 or GIF. A recording shows its length on the thumbnail.

The filters at the top show one kind at a time, with how many there are: All, Screenshots, Recordings and GIF. Tab steps through them. In a narrow window they fold into a dropdown.

The history shows the 300 newest captures. With nothing found it says "Nothing found"; with nothing captured yet, "Nothing captured yet".

Selecting

The current tile has an accent ring round it. Move it with the arrow keys, or click a tile.

  • Ctrl+click adds a tile to the selection, or takes it out (Cmd+click on macOS).
  • Shift+click selects every tile from the current one to the one clicked.
  • Ctrl+A selects every tile shown.

With several selected, the bottom bar says how many, and Copy, Delete and Pin work on all of them. Esc lets go of the selection.

Actions

  • Open (Enter, or a double-click): a screenshot opens in the Editor, a recording in the Studio, a GIF in your system's viewer.
  • Editor / studio (E): the same, for a screenshot or a recording.
  • Copy (Ctrl+C): one screenshot goes on the clipboard as a picture; a recording, a GIF or several captures go as files. The window closes.
  • Pin (P): pins the selected screenshots on top of every window (see Capture).
  • Delete (Del): moves the selected captures to the trash.

Hover over a tile for the same as buttons: Copy and Edit (Studio for a recording) in the middle, Show in folder at the top right, Delete at the bottom right and, for a screenshot, Pin on top at the bottom left.

Drag a tile into a chat, a browser or a file manager to drop the file there.

The gear at the top right opens Settings. The bottom bar lists the keys, and drops the less used ones in a narrow window.

Project files

A .kadr project keeps an edit, not just its finished picture or video. You can reopen it later or move it to another computer and keep working.

How to open

Use kadr open <file> to open a project in the editor or studio, according to its contents. kadr edit <image|project.kadr> opens a screenshot project; kadr studio <video|project.kadr> opens a recording project.

You can also open a .kadr file from the file manager once the file type is registered. On Linux kadr registers it on first run; kadr install-desktop repeats that setup. The Windows installer registers the association. See Install.

Saving

Use Project in the editor or studio to save the original picture or recording and its edit together. The screenshot project keeps every shape; the recording project keeps zooms, cuts and trimming along with the other studio choices.

When you open a project, saving it rewrites the same .kadr file. In the editor, Save also updates that opened project; in the studio, Export does so before making the video. Keep a separate copy first if you want to keep an earlier edit.

Inside the file

A project is a tar archive with the media and editing information together:

  • A screenshot project holds the source picture, added pictures, the drawing and a preview. Black boxes permanently remove what they cover from the editable source too.
  • A recording project holds the video, its click/key/cursor log, the studio edit, and the separate camera recording and wallpaper when present.

Opening unpacks the project into kadr's cache. You do not need to unpack it yourself or keep its source files beside it.

Screenshots

kadr capture opens the bar with every capture mode. kadr shot starts smart selection by default; choose an area, windows, a screen, every screen, the self-timer or the previous area explicitly. kadr shot scroll starts a scrolling screenshot and finishes it when called again. kadr open <file> shows an existing image on a card; kadr pin <file> keeps it above other windows. See Capture.

Recording

kadr record opens the recording bar, or stops the current recording. The region and fullscreen forms start immediately, with optional microphone, system audio, camera, shortcut display and studio mode. The area and previous forms open the bar for a given or last-picked area. kadr record stop stops explicitly. See Recording; the Hyprland click/key log is Linux-only.

Editing

kadr edit <image|project.kadr> opens the editor; kadr studio <video|project.kadr> opens the studio, and its render flag exports immediately. kadr open <file> opens a project in the right editor. kadr trim <video> opens trimming, or trims directly with times in seconds; a start time requires an end time. kadr gif <video> makes a 720px, 15 fps GIF. See Project files for keeping an edit.

Other commands

Open History with kadr history or Settings with kadr settings. kadr text [image] recognizes text in an image, or asks for an area, and copies it. kadr update checks for a release now; kadr tray runs the tray for autostart. kadr install-desktop registers project files on Linux. kadr --version prints the version. The development command is for test hooks, not normal capture work.
