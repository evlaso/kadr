# Настройки

Настройки меняют поведение съёмки, сочетания клавиш, начальные параметры редактора и студии, а также хранение файлов. Изменения сохраняются сразу. Поиск работает по всем разделам: помнить, где находится нужная строка, не нужно.

## Как открыть

Выполните `kadr settings`, нажмите на иконку в трее или используйте назначенный хоткей настроек. По умолчанию на macOS и Windows это Ctrl+Shift+5; на Linux kadr начинает с ваших привязок Hyprland.

Для сочетаний внутри окон в этом справочнике Ctrl означает Cmd на macOS. Глобальные сочетания по умолчанию ниже используют Ctrl и на macOS, и на Windows.

## Разделы

Начните печатать, чтобы найти строку или раздел по названию. Выбор раздела в боковой панели сбрасывает поиск. «Миниатюры» — группа внутри «Основных», а «Редактор» — строка внутри «Скриншотов», не отдельный раздел боковой панели.

| Раздел или группа | Строки и что они меняют |
|---|---|
| Основные | «Язык», «Оформление», «Иконка в трее», «Проверять обновления», «Канал обновлений»: язык интерфейса, системная/тёмная/светлая тема, трей и проверка релизов. |
| Основные → Миниатюры | «Карточка исчезает через», «Где показывать», «Сколько карточек сразу»: 5, 10, 20 секунд или «Никогда»; «Слева» или «Справа»; 2, 4 или 6 карточек. Под курсором карточка остаётся. |
| Скриншоты → После снимка | «Показывать карточку», «Копировать в буфер обмена», «Сохранять в папку», «Открывать редактор», «Закрепить поверх окон»: независимые действия после съёмки. |
| Скриншоты → Файлы | «Папка для скриншотов», «Имя файла», «Тень окна», «Фон снимка окна», «Размер скриншота», «Курсор в скриншотах», «Таймер»: место и имена файлов, вид окна, 1× или «Пиксели экрана», курсор и отсчёт 3/5/10 секунд. |
| Скриншоты → Редактор | «Редактор»: «Окно» или «Поверх всего». Этот выбор есть только на Linux; в остальных системах используется окно. |
| Запись → После записи | «Показывать карточку», «Копировать в буфер обмена», «Сохранять в папку», «Открывать студию». В буфер копируется файл. Записи в режиме студии открываются в студии в любом случае. |
| Запись → Видео | «Папка для записей», «Имя файла», «Частота кадров», «Качество», «Рамка вокруг области». «Как экран» берёт частоту монитора; другие варианты — 30, 60 и 120 кадров в секунду. Рамка в запись не попадает. |
| Студия | «Зум по умолчанию», «Фон по умолчанию», «Отступ по умолчанию»: зумы по кликам и подложка вокруг видео. |
| Текст | «Языки распознавания» перечисляет установленные языки; «Русский язык» предлагает загрузить языковые данные, если их нет. |
| Клавиши | По строке на действие, с назначенными сочетаниями и кнопкой «Добавить сочетание». Подробнее ниже. |
| Хранилище | «Занято», «Удалять старые снимки и записи», «Очистить сейчас»: место на диске и очистка старых файлов. Подробнее ниже. |
| О kadr | Строка kadr показывает версию и «Проверить сейчас» для обновлений; «Интерфейс», «Исходный код», «Файл настроек» дают сведения о приложении и доступ к настройкам. |

«Имя файла» общее для скриншотов и записей. Шаблон принимает `{date}`, `{time}`, `{type}` и `{n}`. «Фон снимка окна» использует вид, сохранённый в [редакторе](editor.md). Каналы и обновление описаны в [установке](install.md).

## Сочетания клавиш

В разделе «Клавиши» нажмите «Добавить сочетание» (+) рядом с действием и нажмите нужную комбинацию. Esc отменяет ввод. Нажатие на существующее сочетание удаляет его. Если назначить комбинацию, занятую другим действием, она перейдёт к новому.

Строки раздела: «Все режимы на одной панели», «Скриншот области», «Скриншот прошлой области», «Скриншот окна или области», «Скриншот экрана», «Скриншот с прокруткой», «Запись экрана», «Запись прошлой области», «Распознать текст», «История» и «Настройки».

Глобальные сочетания по умолчанию на macOS и Windows:

| Клавиши | Что делает |
|---|---|
| Ctrl+Shift+1 | Скриншот области |
| Ctrl+Shift+2 | Запись |
| Ctrl+Shift+3 | Распознать текст |
| Ctrl+Shift+4 | История |
| Ctrl+Shift+5 | Настройки |
| Ctrl+Shift+6 | Скриншот с прокруткой |

На Linux kadr начинает с существующих привязок Hyprland. Установленный хук `data/hypr/kadr.lua` загружает сочетания, сохранённые в этом окне; см. [установку](install.md). На macOS и Windows глобальные сочетания держит трей, поэтому он должен работать.

## Хранилище

«Занято» показывает место и число файлов по категориям «Скриншоты», «Записи» и «Кэш студии». В «Удалять старые снимки и записи» можно выбрать «Никогда», 7, 30 или 90 дней. Включённая автоочистка запускается не чаще раза в день и навсегда удаляет старые снимки и записи kadr, не трогая остальные файлы в этих папках.

Сначала выберите срок, затем нажмите «Очистить сейчас → Очистить», чтобы применить его сразу. Результат сообщает освобождённое место и число файлов. В файле за это отвечает `cleanup_days`; `0` отключает автоматическое удаление. Очистка также убирает данные правки, исходный снимок или запись которых уже удалены.

## Файл настроек

Настройки хранятся в `settings.toml`, на Linux — в `~/.config/kadr`. Откройте «Настройки → О kadr → Файл настроек → Изменить», чтобы править его в системном редакторе. «Показать в папке» открывает его папку.

Правки руками подхватываются, когда kadr в следующий раз понадобится настройка. Окно сохраняет комментарии и порядок строк, меняя только значения, которые вы поменяли в нём. Пропущенная настройка берётся по умолчанию; нечитаемое значение игнорируется. Если TOML-файл сломан, kadr берёт настройки по умолчанию, показывает место ошибки в окне настроек и оставляет файл как есть. До исправления изменения в окне не сохраняются. Старый `settings.json` переносится автоматически и переименовывается в `settings.json.old`.

Ниже группы идут в том же порядке, что в файле. Некоторые настройки есть только в файле, без отдельной строки в окне.

| Ключ | Комментарий |
|---|---|
| `version` | Формат файла. |

### Основные

| Ключ | Комментарий |
|---|---|
| `language` | `"en"` или `"ru"`. |
| `theme` | `"system"`, `"dark"` или `"light"`. |
| `tray` | Иконка в трее. |
| `keep_warm` | Держать выбор области запущенным, чтобы он появлялся сразу; расходует немного памяти. |
| `check_updates` | Проверять новые релизы. |
| `update_channel` | `"stable"` или `"beta"`; если не задан, используется канал этой сборки. |

### Снимки и записи

| Ключ | Комментарий |
|---|---|
| `screenshot_dir` | Куда сохранять скриншоты; если не задано — системная папка картинок. |
| `video_dir` | Куда сохранять записи; если не задано — системная папка видео. |
| `name_template` | Имена новых файлов: `{type}`, `{date}`, `{time}` и `{n}` заменяются значениями. |
| `card_seconds` | Сколько секунд показывать карточку после съёмки; `0` оставляет её. |
| `card_side` | Где показывать карточки: `"left"` или `"right"`. |
| `max_cards` | Сколько карточек показывать сразу. |
| `cleanup_days` | Удалять снимки и записи старше этого числа дней; `0` оставляет их. |

### Скриншоты

| Ключ | Комментарий |
|---|---|
| `logical_size` | Сохранять в 1x: пиксель картинки равен пикселю макета. |
| `shot_cursor` | Добавлять курсор в скриншоты. |
| `window_shadow` | Снимки окон сохраняют тень окна на прозрачном фоне. |
| `window_backdrop` | Имя сохранённого в редакторе вида для фона снимков окон. |
| `timer_seconds` | Таймер: 3, 5 или 10 секунд. |
| `editor_window` | Редактор открывается обычным окном; `false` помещает его поверх всего на Linux. |

### Запись

| Ключ | Комментарий |
|---|---|
| `fps` | Кадров в секунду; `0` — частота экрана. |
| `quality` | `"medium"`, `"high"`, `"very_high"` или `"ultra"`. |
| `region_frame` | Обводить записываемую область; обводка в запись не попадает. |

### Студия

| Ключ | Комментарий |
|---|---|
| `studio_zoom` | Увеличение зумов по кликам, от 1 до 4. |
| `studio_backdrop` | Фон по его месту в списке студии, начиная с 0. |
| `studio_padding` | Сколько фона видно вокруг: от 0 (нет) до 3. |

### Редактор

| Ключ | Комментарий |
|---|---|
| `saved_colors` | Цвета, сохранённые в меню цвета, в виде `"#rrggbb"`. |
| `recent_colors` | Недавно использованные цвета, сначала новые; kadr ведёт этот список сама. |

### После снимка

В таблице `after_shot` пять независимых переключателей:

| Ключ | Комментарий |
|---|---|
| `card` | Карточка в углу экрана. |
| `copy` | Скопировать в буфер обмена. |
| `save` | Оставить файл; если выключено — только временный. |
| `edit` | Открыть в редакторе. |
| `pin` | Закрепить скриншот поверх всех окон. |

### После записи

В таблице `after_video` те же пять переключателей. `pin` относится к скриншотам, не к записям; строки для записи в окне нет.

| Ключ | Комментарий |
|---|---|
| `card` | Карточка в углу экрана. |
| `copy` | Скопировать в буфер обмена. |
| `save` | Оставить файл; если выключено — только временный. |
| `edit` | Открыть в студии. |
| `pin` | Закрепить скриншот поверх всех окон; к записям не применяется. |

## Клавиши

Если не идёт запись сочетания или редактирование имени файла:

| Клавиши | Что делает |
|---|---|
| Ввод текста | Искать по всем разделам |
| Backspace | Убрать последний символ поиска |
| Tab или Down | Следующий раздел |
| Up | Предыдущий раздел |
| Esc | Сбросить поиск; без поиска — закрыть окно |
| Esc при записи сочетания | Отменить без назначения |
| Enter, Tab или Esc при редактировании «Имя файла» | Завершить редактирование шаблона имени |

## Команды

