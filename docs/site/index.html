Screenshots and screen recording for the desktop

Capture an area, a window or the screen, annotate it, record with your camera and clicks, and turn a recording into a polished video. Native, written in Rust. Linux first; macOS and Windows in the works.

Download

Builds for Linux, macOS and Windows on the releases page. Alpha: things change between versions.

One bar for everything

Area, screen, window, scrolling shot, self-timer, text recognition and recording behind a single hotkey.

An editor that keeps up

Arrows, boxes, text in seven styles, step numbers, a highlighter that follows a line of text, hiding that can't be undone, a background and a shadow.

Recording with a studio

Microphone, system audio, a camera bubble. The studio adds zooms on clicks, cuts, a smooth large cursor, and exports MP4 or GIF.

Project files

A .kadr file keeps the original and every shape, zoom and cut, to open again later or on another computer.

Yours to tune

Settings with search, hotkeys, English and Russian, dark and light themes following the system, and a settings.toml with a comment on every line.

Open source

MIT. One native binary, no web view. Built on GPUI CE.

Status. kadr is used every day on Linux (Wayland, Hyprland). The macOS and Windows builds pass their end-to-end test in CI but haven't been tried on a real machine yet; testers are very welcome. The manual says what works where.
