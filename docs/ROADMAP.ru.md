# kadr — роадмап

Цель: по качеству и объёму возможностей не уступать CleanShot X (скриншоты, оверлей, редактор) и
Recordly (запись, студия), и быть заведомо лучше встроенных средств ОС (Snipping Tool, macOS Screenshot,
GNOME Screenshot / Spectacle). Плюс то, чего нет ни у кого: Linux/Wayland как первоклассная платформа,
нативная скорость без Electron и webview, агентный режим (MCP), открытый код.

Статусы в матрице: ✅ есть · 🟡 частично · ⬜ нет · ❌ не делаем · — к платформе не относится. Платформы:
L — Linux (Wayland, Hyprland), M — macOS, W — Windows. ✅ на M/W — общий код без своей части под ОС
или то, что проверено desktop-e2e; где есть код под ОС, который ещё не запускался там, — 🟡. Колонки платформ заполняет и поддерживает агент по факту кода; «ориентир» — у кого
это уже есть (CS = CleanShot X, R = Recordly, OS = встроенные).
Архитектура, бюджеты и тесты — в `SPEC.ru.md`; здесь только что и в каком порядке.

## Чего не делаем

- Своё облако, аккаунты, команды, SSO — это бизнес CleanShot, не продукт kadr. Шаринг — только в хранилище пользователя.
- Транскрипция речи в видео — субтитры идут из сценария (§11); распознавание — не раньше 1.0 и только локальное.
- Webview, Electron, встроенный браузер — никогда.
