# Security

kadr handles what's on your screen, so problems with it matter. If you find
one, please don't open a public issue. Report it privately:

- through GitHub: **Security → Report a vulnerability** on
  [the repository](https://github.com/evlaso/kadr/security), or
- by email to security@kadr.sh.

Say what's affected, how to reproduce it, and the kadr version and system.
You'll get an answer within a week; a fix goes into the next release, and
you're credited in its notes unless you'd rather not be.

Only the latest release is supported. Before the first release (0.3.0),
that's the `main` branch.
