Roadmap

The goal: as good and as complete as the best dedicated screenshot and screen-recording tools (capture, the picker, the editor, recording, the studio), and clearly better than what the systems ship with. Plus what nobody has: Linux on Wayland as a first-class platform, native speed with no webview, agent mode (MCP), and open source.

Status marks: there · partly · not yet · won't do · — doesn't apply to the platform. Platforms: L is Linux (Wayland, Hyprland), M is macOS, W is Windows. on M or W means shared code with no part of its own for that system, or something desktop-e2e has checked; where there is code for that system that hasn't run there yet, it's . The platform columns are kept up to date from the code.

Architecture, budgets and tests are in the spec, SPEC.md; this file says only what comes and in what order.

Not planned

  • A cloud of our own, accounts, teams, SSO: that's a hosting business, not kadr. Sharing goes only to the user's own storage.
  • Speech transcription in videos: subtitles come from the script (§11); recognition not before 1.0, and only local.
  • Webview, Electron, a built-in browser: never.
